transitions: shape-aperture dive (the logo's own shape) · circle/slit wipes · object becomes object (cards → points of light → agents → light → logo) · lanes converge.

motion_feel: ease-out entrances, in-out travels, gravity eases for falling objects; idle drift on everything held.
sound: chord-per-world (see slots), glass tick notes for many small objects (every 2nd–3rd only), bells on each lit node, boom + triad on the logo, ≤ 3 air moves.
