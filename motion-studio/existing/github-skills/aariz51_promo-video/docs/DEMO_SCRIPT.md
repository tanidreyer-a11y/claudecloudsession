# LaunchLayer Demo Script

Target length: **2 minutes 40 seconds**. Speak clearly over a screen recording. Do not submit a silent walkthrough.

## 0:00-0:18 - Problem

**Screen:** Landing hero.

“AI has solved how quickly we build products, but distribution has not caught up. Creating a credible launch film still means coordinating reference research, creative direction, motion, voice, sound, and multiple formats. LaunchLayer turns that entire process into one observable agentic workflow.”

## 0:18-0:42 - Inputs and Guardrail

**Screen:** New-project wizard; move through Product, Reference, Assets, and Delivery without submitting.

“I give LaunchLayer the product truth, real app screens, a logo, and a motion reference. The reference is style-only: the agent learns pacing, composition, typography, transitions, and camera language, but never reuses its footage, copy, music, or brand.”

## 0:42-1:20 - Agentic Layer

**Screen:** Existing SafeMama project and its completed pipeline. Slowly point to the nine stages.

“This is where the agentic UX matters. Instead of one black-box spinner, LaunchLayer exposes nine durable responsibilities. It secures an isolated Sandbox, validates inputs, watches 36 chronological frames, studies the app, creates direction and a storyboard, writes the Remotion production, builds synchronized narration and sound, then verifies and renders. Every stage is persisted, readable, and recoverable across refreshes.”

## 1:20-1:58 - Real Output

**Screen:** Public `/demo`; play 8-10 seconds of vertical, expand it, then play 8-10 seconds of landscape.

“These are the real outputs from one SafeMama brief, not mockups: a native vertical film and a native landscape film from the same frame-locked production. The audio pipeline measures every voice take before scheduling it, so narration never overlaps and product names remain clear.”

## 1:58-2:25 - Technical Proof

**Screen:** Public demo agent trace, then GitHub README architecture and a quick view of commit history.

“Under the hood, Vercel Workflow provides durable orchestration, Vercel Sandbox runs the media and code toolchain, OpenRouter handles multimodal reasoning and voice, Remotion renders the film, and Supabase protects project state and final media. ChatGPT Codex helped turn my existing Promo-Video system into this tested SaaS; the public history shows each reliability and product decision.”

## 2:25-2:40 - Close

**Screen:** Return to landing hero or both output cards.

“LaunchLayer is the distribution layer for AI apps: one brief in, an original launch system out. Building is solved. Now distribution can be too.”

## Recording Notes

- Record at `1920 x 1080`, 30 or 60 FPS, with a clean browser and notifications disabled.
- Use your own spoken narration. A face camera is optional; a 3-5 second face introduction can add authenticity, but the product should remain the focus.
- Use the completed project and public demo. Do not run a paid 15-minute generation live.
- Show a short accelerated pipeline clip only if needed, then clearly label it as an existing completed run.
- Keep the final export below 3 minutes. Aim for 2:35-2:45 to leave margin.
- Add subtle captions for clarity, but do not cover the pipeline labels or video previews.
