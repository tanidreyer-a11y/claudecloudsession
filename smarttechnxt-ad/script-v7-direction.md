# SmartTechNXT v7: reference-led direction (about 35 s, Option A / FICA)

## What the 4 references share

| Ref | Look | Technique to steal |
|---|---|---|
| 1. Eleven Agents (dark) | Black, pixel particles, glowing orbs | ONE line travels and drops vertically, hanging an orb; almost no hard cuts |
| 2. Eleven Agents (light) | Off-white, real UI cards, gradient orbs | Line splits into paths, toggles flip, **compliance badge grid**, bars close into the logo |
| 3. Zelios / NeuraFlow (dark blue glass) | Navy glass, top spotlight, glow | Typing prompt, orbiting icons around a centre, **3D glass card carousel** |
| 4. Localised ads (light, cream) | Gradient tiles, stacked cards | Tree branches from one node to many tiles, fast **vertical scroll** through stacked cards |

Common rules: a new beat every 2 to 3 s, continuous transitions (an object carries you into the next scene
instead of a cut), real-looking UI, one glowing "hero" object, the camera moving up, down, in and around.

**Base look: ref 3.** Its navy glass is close to SmartTechNXT's `#163456`. Swap its blue glow for lime `#B2CB07`.
Borrow the travelling line from ref 1, the badge grid and logo close from ref 2, and the branching and vertical scroll from ref 4.
