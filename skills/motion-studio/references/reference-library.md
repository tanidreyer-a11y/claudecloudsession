# Reference library

The user's reference clips are third-party ads, so they are **not** bundled. These breakdowns capture what matters.
To analyse new references: `scripts/analyze_reference.sh <video>` (contact sheet + cut detection), then describe
look, focal object, camera directions, transitions, element types, pace (beats/s) and sound sync.

## R1 — ElevenLabs "Eleven Agents" (dark) — the user's favourite
- Look: near-black, soft blue/violet/teal gradient glows, white type.
- Focal object: a single line / orb; the eye stays on one spot and is pulled **deeper**.
- Sequence: pixel particles rain into a floor → channel icons (phone, chat, mail, WhatsApp) branch into one line →
  a vertical line **drops** and hangs a glowing orb → chat bubbles over blurred gradient ("Ok Holly, we've processed
  your return…") → knowledge-base card with branching lines → ring "24/7" → globe orb → logo from its "II" mark +
  descriptor + "Talk to sales" pill.
- Cuts: ~1 hard cut in 30 s. Everything is carried by objects. Beat every 2–3 s.
- Voice: calm, declarative; talk, pause to sink in, repeat.

## R2 — ElevenLabs "Eleven Agents" (light)
- Off-white canvas, real UI cards ("High severity · Resolution dropping…"), line splitting into Variant A/B paths with
  gradient orbs travelling, toggles ("Refund eligibility guardrail"), compliance badge grid (SOC 2, ISO, HIPAA, GDPR),
  cloud-lock icon, wireframe globe on green gradient, circles merging, two bars closing into the "II" logo.
- Lesson: badges = instant trust, but only show true certifications.

## R3 — Zelios / "NeuraFlow" (navy glass)
- Deep navy glassmorphism, top spotlight cone, glow edges. Typing prompt "How NeuraFlow.AI can help?" → chat with AI
  agent → answer card; icons orbiting a "New Updates" core; 3D carousel of glass cards.
- Closest to navy brands; swap blue glow for the brand accent.

## R4 — Localised ad variants (cream)
- Node tree branching from a pause/logo mark to gradient app tiles (Meta/Google/LinkedIn Ads), fast vertical scroll
  through stacked ad cards in many languages, labelled gradient orbs ("Voice", "Tone").
- Lesson: vertical scroll + branching trees make "scale" visible.

## R5–R9 — see their Style Cards (Kinetic Pop, Cobalt Campaign, Sunset Prompt, Lavender Desk, Desert Glass)
Re-checked frame by frame on 2026-10-07; the cards' beat lists are accurate. Extra notes from the re-watch:
- **R5 Kinetic Pop:** the rolling word slot ("Your ✓ Product / App / Agency / Story") is a vertical list whose centre
  row is the hero; gradient blue→red full-bleed for "Show what matters"; the chart arrow overshoots the frame; the CTA
  is *clicked by a visible cursor* — the click is the last beat.
- **R6 Cobalt Campaign (NIVO):** light → dark → light is the act structure (chapters flip the ground); the isometric
  'Data' slab assembles from 5 tiles; the agent tree is a bracket with 4 rows that tick one by one.
- **R7 Sunset Prompt:** a phone-first launch; the giant headline is set vertically ("Think deeper / faster") because
  the recording is portrait — a vertical film can rotate type 90° for scale.
- **R8 Lavender Desk:** the verb list (Analyze · Research · Review · Deliver) stays on the left and highlights per
  chapter while the right side changes ground colour (lavender → white → mint).
- **R9 Desert Glass:** photographic landscape as the ground the whole time; frosted UI windows ride over it; the film
  ends on the same landscape at dusk with the logo — time of day = progress.
