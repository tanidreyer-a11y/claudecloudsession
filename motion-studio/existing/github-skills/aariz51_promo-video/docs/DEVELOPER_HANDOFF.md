# Developer Handoff

LaunchLayer was created for the ChatGPT Codex Hackathon by productizing Aariz's existing `Promo-Video-` generator as a Next.js SaaS. The production authority lives under `generator/promo-video/`: it analyzes a video strictly as a style reference, studies real application screens and branding, plans an original campaign, customizes the nine-scene Remotion system, builds synchronized narration and sound, validates the production, and renders selected formats. Vercel Workflow provides durable stages and Vercel Sandbox runs `yt-dlp`, FFmpeg, Python, Chromium, and Remotion in isolation. Changes should preserve the style-only boundary, generated-file allowlist, frame-locked timing, and protected non-overlapping voice scheduler.

The app intentionally reuses the Caption AI Supabase project and its existing user identities. LaunchLayer state is isolated in the RLS-protected `launchlayer_projects` table, lightweight audit records use the `launchlayer.project.*` namespace, and media uses private `launchlayer-assets` and `launchlayer-renders` buckets. Apply all SQL files under `supabase/migrations` when provisioning a replacement project. The public `/demo` route is a narrow hackathon exception: it can sign only two fixed SafeMama MP4 IDs and must never become a generic public project reader.

Use the existing OpenRouter account through `OPENROUTER_API_KEY`; creative, vision, and TTS model IDs are configurable through `.env.example`. The default narrator is `coral`. The audio runtime receives the app name separately, splits camel-cased names for clear speech, measures natural takes, and schedules them sequentially with a mandatory gap. Do not remove `schedule_voice_cues`, `MIN_VO_GAP`, `spoken_text`, or the corresponding workflow validation. Stripe and billing are intentionally absent from this hackathon version.

Only final requested MP4 files are persisted. Intermediate frames, production source, creative plans, voice cache, and archives stay inside the temporary Sandbox and are deleted with it. `CRON_SECRET` protects `/api/cron/cleanup`, which removes expired LaunchLayer media without touching Caption AI data. Production starts with a free OpenRouter credit check, paid stages have bounded retries, and completed creative work is recovered rather than repeated after delivery failures. Do not perform paid end-to-end tests until static verification passes and the owner explicitly approves the spend.

Keep credentials in this repository's `.env.local` or Vercel environment settings using `.env.example` as the exact contract. Never commit or paste values into docs, prompts, screenshots, logs, or issues. For local Sandbox use, explicit `VERCEL_TOKEN`, `VERCEL_TEAM_ID`, and `VERCEL_PROJECT_ID` are supported; production should use Vercel's platform identity. Before release, run `npm run verify`, test sign-in, open `/demo` in a private window, confirm both videos and fullscreen mode, verify the cleanup route rejects unauthorized requests, and inspect the final Git diff for secrets.
