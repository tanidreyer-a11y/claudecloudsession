# ad-marketing-10k (Claude skill)

House playbook for high-end SaaS/B2B product films built in code — merged from the Debi promo (Remotion) and the
ADC / SmartTech NXT films (HTML engine). Intake questions → concept → paced voice script → brand extraction from a
PDF bible → word-synced motion (zoom-throughs, spline camera, UI templates, bubbles, lines, geometry) → musical sound
design → grade/grain/loudness finishing → delivery → pricing. Includes 41 documented mistakes so they don't repeat.

Install: click "Save skill" on the .skill file in Claude, or copy this folder to `~/.claude/skills/ad-marketing-10k/`.
Pipeline needs: Node (+ Remotion or Playwright/Chromium), ffmpeg (or `pip install imageio-ffmpeg`), Python 3 with
`numpy scipy pymupdf pocketsphinx`. Start with `SKILL.md`, then `references/lessons-learned.md`.
