# Remotion template (Debi promo, ADC Innovations)

Included: `package.json`, `tsconfig.json`, `remotion.config.ts` from the Debi build.
To complete the template, copy in from the Debi project folder (zip it WITHOUT node_modules):
`src/` (index.ts, Root.tsx, timeline.ts, theme.ts, shots/…), `scripts/` (cues.mjs, render.mjs, finish.mjs, stills.mjs),
`audio/` (build_audio.py, analyse_vo.py). Then: `npm i` → `npm run studio` / `npm run build`.
See `references/remotion-engine.md`.
