### Recipe A — Sunset Prompt base × Kinetic Pop donor
_Parts drawn from: Sunset Prompt, Kinetic Pop, Lavender Desk. Wildcard slot: colour. Needs: ui._

- **structure**: Launch teaser — product chip → typed promise → word-swap claims → "Available now"
- **pacing**: Short punch — 10–20 s, 0.4 cuts/s, sparse sound
- **camera**: Locked frame — motion lives in type and elements
- **transitions**: Hard cut on the downbeat + Vertical word roll / slot-machine swap + Prompt "send" button is the cut to the result
- **typography**: Two-word claim, second word swaps and changes colour
- **colour**: Paper ↔ charcoal flips + one loud gradient for hero frames
- **ui_treatment**: Glass prompt bar + result cards, tables, trend chips, file chips
- **motion_feel**: Crisp 200–300 ms ease-out, human typing cadence
- **sound**: Sparse — key clicks, one tone per swap, silence as a sound
- **hook**: A promise being typed in a prompt bar
- **fonts**: Inter (OFL), DM Sans (OFL)
