# ADC Innovations brand video v2: "One Loop" (about 95 words, about 38 s)

Voice style: ElevenLabs-like. Calm, exact, declarative. Short sentences that state what is true.
ElevenLabs: Speed 1.0, Stability 50, Style 20 to 25, one take. Use "..." only where written.

## Script

Every business runs on work... that nobody sees.
Invoices to chase. Bills to capture.
Leads to answer. People to onboard.

Now... it does itself.
Almost.

Meet ADC agents.
Digital co-workers, each built for one job.
And each one... done with precision.

They read the document.
Check every detail.
Act... in seconds.

But before anything leaves...
it comes to you.

One loop.
The agent prepares. You approve. It's done.
Every action... on record.

Choose the agents you need.
Add more... as you grow.

ADC Innovations.
Precision... at work.

Book your fifteen-minute demo.

## Visual spine

| VO | Visual |
|---|---|
| Work nobody sees | One point of light. Four faint task cards orbit it: Invoice, Bill, Lead, Onboarding. |
| Now... it does itself. | The cards snap into motion, each processing on its own. |
| Almost. | Everything freezes for a beat. (The hook.) |
| Meet ADC agents... each built for one job | The point splits into distinct agents, each locking onto its card. |
| Read / check / act | Camera dives into one card: the scan line, fields ticking, action sent, in 3 beats. |
| Before anything leaves... it comes to you. | The action travels to a single "Approve" button at the centre. |
| One loop. Prepares / approve / done | The path closes into a ring and the dot runs the loop 3 times as each word lands. |
| Every action on record | The ring leaves an activity log trail. |
| Choose the agents you need | Pull back: a grid of agent tiles; they toggle on one by one and the grid expands. |
| Precision... at work. | Everything collapses into the ring, which resolves into the logo. CTA pill. |
